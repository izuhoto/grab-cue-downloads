# GrabCue Downloads

This repository hosts the distribution site content for **GrabCue**, a macOS menu bar app for text actions, snippets, and clipboard history.

GrabCue keeps useful text actions close at hand. Select text to bring up quick actions, search commands from the keyboard, insert saved snippets, convert text or units, and reuse clipboard history when something you copied earlier becomes useful again.

## Platform

- macOS 14 (Sonoma) or later

## Key Features

- Select text and quickly choose actions such as copy, search, dictionary lookup, calculation, spoken reading, or large display.
- Search and run common actions from the keyboard, including opening apps, opening settings, opening web links, controlling music, and switching sound input or output.
- Add your own actions and turn them on or off after reviewing what they do.
- Save text snippets and insert them when needed, with groups plus import and export.
- Find and reuse copied text, images, and files from clipboard history. You can keep selected apps out of the history.
- Collect multiple history items and paste them one after another. You can add a newline, space, or your own text between pasted items.
- Change selected text casing, sort or shuffle lines, add or remove surrounding marks, prepare text for the web, and check character or word counts.
- Convert length, weight, temperature, time, speed, area, volume, angle, and more. Japanese eras, binary and hexadecimal numbers, degrees-minutes-seconds, and measurement names used in the Bible are also supported.
- Adjust shortcuts, text size, menu order, enabled features, and launch at login.
